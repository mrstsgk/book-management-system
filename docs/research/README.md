# 調査メモ

論点（GitHub Issue）を調べた結果のうち、長いもの（根拠・出典つき）を置く場所。要件の正本ではなく、判断の材料。
短い調査はメモを作らず、論点の Issue にコメントする。

## Issue へのコメント

メモを置いたら、同じ作業で該当する論点の Issue に、要点・推奨案（案であり決定ではない）・メモへのパスをコメントする。コメントしないと、Issue を見た人がメモに気づけない。

Issue の本文への反映は、論点を整理するときにオーナーが行う。

## ファイルの置き方

- パス：`docs/research/{フォルダ}/{ファイル名}.md`
- フォルダ：下の対応表から選ぶ。表にない名前を作らない
  - どのまとまりにも入らないものは `common/`
  - status-map.md に新しいまとまりができて表にない場合は、表に1行追加し、追加したことを報告する
- ファイル名：何を調べたかが分かる英語。小文字・ハイフン区切り（例：`cover-sources.md`）
- 中身は日本語でよい
- 1行目に関係する論点の番号を書く（例：`関連する論点: Q-001`）。なければ `関連する論点: なし`
- 追記してよい。過去の記述は消さず、日付を付けて追記する

## まとまりとフォルダの対応表

### 公開側

| まとまり（status-map.md） | フォルダ |
|---|---|
| 読んだ本の一覧 | `public-book-list` |
| 読んだ本の詳細 | `public-book-detail` |
| 分野別の集計 | `public-tag-counts` |

### 管理側

| まとまり（status-map.md） | フォルダ |
|---|---|
| ログイン・ログアウト | `admin-login` |
| 本の一覧（管理） | `admin-book-list` |
| 本の登録 | `admin-book-register` |
| 本の編集・削除 | `admin-book-edit` |
| 分野タグの管理 | `admin-tags` |

### 共通

| 内容 | フォルダ |
|---|---|
| 書誌・書影の外部カタログ | `common-catalog` |
| 起動時の見本データ | `common-sample-data` |
| どのまとまりにも入らないもの（対応ブラウザなど） | `common` |
