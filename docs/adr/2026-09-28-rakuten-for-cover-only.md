# 楽天ブックスは書影を補う用途だけに使い、書誌は openBD だけから取る

**日付:** 2026-09-28
**状態:** 採用
**カテゴリ:** architecture
**参照:** 一部を置き換え: [書影は外部カタログ（openBD・楽天ブックス）の URL を表示し、自前の画像アップロードをやめる](./2026-09-28-book-cover-from-external-catalogs.md)、[要件定義](../specifications.md) §1.1・§1.2

## 背景・経緯

これまでは openBD に本が無いとき、楽天ブックスの書誌（書名・著者・出版社・発売日）と書影を丸ごと使っていた。

楽天ウェブサービスの規約では、価格・販売可否以外の情報を持てるのは最長3か月で、削除の指示にはすぐ従う必要がある（[楽天FAQ](https://webservice.faq.rakuten.net/hc/ja/articles/900001974343)）。書誌まで楽天から取ると、期限を過ぎて取り直せない本の書誌を消し、書名の代わりに ISBN を見せる仕組みまで要る。

一方、登録する本（技術書4冊）はすべて openBD に書誌があり、楽天が要るのは書影だけだった（2026-09 に確認）。

## 決定

- 書誌は openBD だけから取る。openBD に無い本はカタログに無い本として扱い、登録できない
- 楽天ブックスは、openBD の本に書影が無いときに書影を補う用途だけに使う
- openBD の書名が実際と違う本は、書名の上書き（要件定義 §1.1）で直す

## 検討した代替案

| 案 | 概要 | 却下理由 |
|---|---|---|
| A（採用） | 楽天は書影だけ | 楽天由来の情報が書影と商品ページの URL に限られ、期限切れの扱いが「書影を消す」だけで済む |
| B | 今のまま楽天の書誌も使う | 登録する本に必要が無いのに、書誌を消す・書名の代わりを見せる仕組みまで要る |

## 判断基準（任意）

openBD に無い本を登録したくなったら、楽天の書誌を使うより先に、書誌を自分で入力する方式を検討する（外部の保持期限に縛られないため）。
