# 入力・相関バリデーションの違反を 1 回の 400 でまとめて返す

**日付:** 2026-11-02
**状態:** 採用
**カテゴリ:** architecture
**参照:** [`docs/architecture.md`](../architecture.md) §4「バリデーションの全件返却」、[`docs/design/admin-screens.md`](../design/admin-screens.md)「相関ルール」

## 背景・経緯

- Request DTO の `validate` タグの違反は `errors[{field, rule}]` で全件返していたが、Domain VO（ISBN の形式）や UseCase（存在しないタグ）の違反は `ErrInvalid` の 400 を 1 つずつ返し、`field` が無いため FE は画面上部に汎用の文言しか出せなかった。利用者は直すたびに次の違反を知ることになる
- 同じ ISBN・同じタグ名の重複を DB の一意制約の 409（`ErrConflict`）で返していたため、楽観ロックの競合（`version` 不一致）と同じステータスになり、FE は 409 を「登録では重複、更新では競合か重複のどちらか」と文脈で読み分けていた。タグの改名では区別できず、文言があいまいだった
- 概要設計（`docs/design/<機能>.md`）に「あってはならない状態」（相関ルール）を書く場所を作ったので、API の契約とテストにそのまま対応づけたい

## 決定

- 入力検証・VO の不変条件・相関ルールの違反は、すべて 400 の `errors[{field, rule}]` に、独立して判定できるものをまとめて返す。`rule` は validator のキーワード、VO 由来は `format` / `invalid`、相関ルールは `x-correlation-rules` の `id`
- 409 は楽観ロック（`version` 不一致）だけに使う。重複は相関ルール（`isbnDuplicated` / `tagNameDuplicated`）として 400 で返す
- 相関ルールは概要設計の CR-xx → Handler の swag 拡張 `@x-correlation-rules` → UseCase の実装 → FE の文言の対応表、の 1 本の流れで追えるようにする
- 外部カタログ（openBD）への照会は、他の違反が 1 つも無いときだけ行う。重複の検査（DB）は照会の前に行う
- DB の一意制約は残し、UseCase の検査をすり抜けた同時登録は従来どおり 409 にする（FE は想定外として共通の文言）
- `code` / `params`（業務ルール違反のコードと差し込み値）は導入しない

## 検討した代替案

| 案 | 概要 | 採否・理由 |
|---|---|---|
| 重複を 409 のままにする | 一意制約違反を 409 で返し続ける | **不採用**。FE が同じ 409 を「重複」と「競合」の 2 つの意味で扱い、改名では区別できない。重複は利用者が直せる入力の問題なので、入力欄の近くに出せる 400 の `errors` が合う |
| `code` / `params` を `ErrorResponse` に足す | 業務ルールの違反（対象なし・編集禁止など）をコードで返し、差し込む値も渡す | **保留**。今の業務ルール違反は 404・401・403・429 のステータスで足りていて、文言に差し込む値（残り件数など）も無い。必要になった機能の PR で足す |
| 外部カタログも常に照会する | 他の違反があっても `isbnNotInCatalog` を同時に返す | **不採用**。登録できない入力のために外部 API を呼ぶのは無駄で、openBD の利用規約上も好ましくない。ISBN は「確かめる」で先に照会しているので、2 回目の送信で分かる程度の不便は許容する |
| 重複の検査を一意制約だけに任せ、制約違反を 400 に読み替える | 事前の `Exists*` 検査を持たず、挿入の失敗から `isbnDuplicated` を作る | **不採用**。他の違反と同時に返せない（挿入まで進まないと分からない）。事前検査 + 制約の二段構えにする |

## 判断基準

- 利用者が直せる入力の問題は、入力欄に対応づけられる 400 の `errors[{field, rule}]` で、まとめて返す
- ステータスは「利用者が次に何をすればよいか」で分ける。同じステータスに複数の意味を持たせない
- 外部 API は、呼ばなくても結果が決まるときは呼ばない
