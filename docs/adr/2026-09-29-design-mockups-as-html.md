# 画面のモックは HTML と PNG でリポジトリに置く

**日付:** 2026-09-29
**状態:** 採用
**カテゴリ:** architecture
**参照:** [`docs/design/public-screens/`](../design/public-screens/README.md)、なし（口頭決定）

## 背景・経緯

単位2（公開画面）は、本実装の前に画面イメージを固めてから進めることにした。モックは Claude の Artifact（デザインキャンバス）で作ったが、Artifact は非公開のリンクで、リポジトリの外にある。要求定義 §2 のとおり渡すのは GitHub のリポジトリだけなので、採用担当・レビュアー・後から読む AI がリポジトリの中でデザインを見られ、変更を PR でレビューできる形が要る。

## 決定

- モックは依存のない静的 HTML として `docs/design/<画面群>/` に置き、これを正とする
- GitHub 上でそのまま見られるように、HTML から書き出した PNG を `images/` に置き、README に埋め込む。HTML を変えたら同じ PR で PNG も書き出し直す（手順は各 README）
- モックは見た目の合意に使う。画面が満たすことの正は要件定義（`docs/specifications.md`）のままにする

## 検討した代替案

| 案 | 概要 | 却下理由 |
|---|---|---|
| A（採用） | 静的 HTML ＋ 書き出した PNG をリポジトリに置く | テキストなので差分を PR でレビューでき、PNG で GitHub 上でも一目で見られる。アカウントも追加の依存も要らない |
| B | Figma ファイル | Figma のアカウントと認証が要り、`.fig` はバイナリで差分が読めず PR でレビューできない。リンクで渡すとリポジトリの外に出る |
| C | Artifact のリンクだけを残す | 非公開でリポジトリの外にあり、「リポジトリだけを渡す」に反する |
| D | Storybook | 表示部品ができてからの道具で、まだ部品が無い。`frontend/architecture.md` §3.1 でページ丸ごとは対象外としている |

## 判断基準（任意）

設計の成果物は、リポジトリの中でテキストとして差分をレビューでき、GitHub 上で追加のツールなしに見られる形を優先する。
